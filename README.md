
### About me

I work across a broad range of projects, which keeps my skills sharp and my curiosity engaged. On the systems side, I've built a 3D raycasting game in C and an IoT-backed blockchain solution for pharmaceutical supply chain monitoring. On the web side, I've developed API-driven single-page applications, a music statistics tool, and a dynamic calendar. Whether I'm working close to the hardware or crafting an interactive UI, I bring the same focus to clean, purposeful implementation.

### What I'm working on

- Improving **Project-TV-Show**: Project TV Show is a front-end TV library that lets users browse popular shows, search by title or genre, and explore episode details from the TVMaze API. It was built as a lightweight, accessible single-page app to practice DOM manipulation, async data fetching, and interactive UI filtering.
